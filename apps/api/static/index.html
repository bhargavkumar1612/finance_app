Overview

Use the tabs above to:

  • Accounts — List and create bank/cash accounts.
  • Transactions — List recent transactions.
  • Chat — Ask to add expenses, net worth, spending (e.g. "add 500 for Swiggy", "what is my net worth?").
  • Import — Upload a CSV (e.g. HDFC), review rows, then confirm to add to ledger.

Open API docs (Swagger) to call endpoints directly.
